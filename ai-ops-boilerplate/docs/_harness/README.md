# `_harness/` — about the harness (not part of your automation)

These documents describe the **AI-Ops Automation Harness itself** — its rationale,
design decisions, and value story. They are here for context when you adopt the template.

They are **not** part of the automation you build from this template. If you don't need
them in your automation repo, delete this whole folder — nothing in the harness depends
on it.

| File | What it is | Audience |
|------|------------|----------|
| `CAPABILITIES.md` | What the harness produces — the capability catalogue + run-time artefacts. | Anyone evaluating/adopting |
| `DESIGN_DECISIONS.md` | The design journal — why the harness is shaped the way it is (the editable source). | Engineers |
| `DESIGN_DECISIONS.html` | Technical docs-site rendering of the journal. | Engineers |
| `DESIGN_DECISIONS.docx` | Confluence-style Word rendering of the journal. | Confluence / sharing |
| `solution.html` | The value-forward, six-page solution document. | Leadership / stakeholders |
| `ai-ops-harness.html` | Solution & technical reference overview. | Mixed |

> For **how to build an automation** with this template, see `docs/AUTHORING.md` and the
> top-level `README.md` / `CLAUDE.md` — those stay with your automation.
