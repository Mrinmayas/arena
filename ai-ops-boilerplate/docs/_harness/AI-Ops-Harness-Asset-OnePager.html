› What is this asset about?

The AI Ops Harness is a vetted starting point a team copies before building a new operations automation. The framework carries the skeleton, audit trail, portal & Excel machinery and tests; six built-in AI skills guide the build in the team's house style. Each new tool ships in ~35% less build effort, runs deterministically on the operator's machine, and arrives with its tests, audit sign-off and operator documentation already in place. Built with agentic AI — with no LLM at runtime, so every run is reproducible and auditable.

One asset · seven deliverables
1 · Copy-paste-ready code framework
The project skeleton + vendored core (audit · Excel · portal login · orchestration · docs), a Playwright recorder and a test harness — explicitly wired, laptop-runnable in one command.
2–7 · Six build-time AI skills
Observability — who did what: the four-eyes audit & sign-off trail.
Excel automation — safe, corruption-free output, correct to the cent.
Portal login — resilient SSO / portal automation, Conditional-Access ready.
Test generation — golden-file tests that fail on a cent of drift.
Doc generation — README + an operator-friendly Word guide from one source.
Workflow diagram — a draw.io process diagram from that same source.
